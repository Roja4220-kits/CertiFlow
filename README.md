# CertiFlow — bulk certificate generator

## Folder layout
```
app.py  certificate_generator.py  template_ocr.py  models.py            <- web app, PDF output, OCR, database
validation.py  mapping.py  participants.py  fieldnames.py                    <- data checks, column suggestions, file reading
templates/index.html                          <- page (includes the "Prepare your files" guide)
static/certiflow.css  app.js                  <- ONE stylesheet for the whole page (old style.css / enhancements.css are no longer used)
examples/                                     <- sample template (PDF/PNG) + sample data (CSV/XLSX)
fonts/                                        <- optional: drop .ttf/.otf files here (e.g. NotoSansTelugu-Regular.ttf)
tests/  test_app.py  conftest.py              <- tests
scripts/make_examples.py                      <- regenerates examples/
```

## Run locally
```
pip install -r requirements.txt        # Windows: install Tesseract and keep its default path
python app.py                          # http://127.0.0.1:5000
```

## Tests
```
python -m unittest tests.test_validation tests.test_validation_v2 tests.test_validation_api tests.test_generator_logic -v   # no extra install
pip install -r requirements-dev.txt
pytest -q                              # also runs test_app.py: real PDFs, database, background jobs, ZIP
playwright install chromium && python tests/ui_check.py   # drives the real UI in a browser, saves screenshots to /tmp
```

## Telugu / Hindi / other languages
1. Download a font that supports the language (free): *Noto Sans Telugu*, *Noto Sans Devanagari* ... from fonts.google.com.
2. In the app: *Field mapping > Upload font*, then pick it in "Font family" (or "Use for all fields"). Or put the file in `fonts/` once for everyone.
3. Needs PyMuPDF >= 1.24. Always check with **Preview first participant** before generating a big batch.

## Public deployment
```
docker build -t certiflow .
docker run -p 8000:8000 -v certiflow-data:/data certiflow
```
Put it behind HTTPS (Caddy, nginx, or your platform's router). Keep **one gunicorn worker** (the Dockerfile does).

| Variable | Default | Meaning |
|---|---|---|
| `CERTIFLOW_DATA_DIR` | app folder | where uploads, PDFs and the database live (mount a volume) |
| `CERTIFLOW_TRUST_PROXY` | off | set `1` behind a proxy so rate limits see real client IPs |
| `CERTIFLOW_MAX_UPLOAD_MB` | 25 | max request size |
| `CERTIFLOW_MAX_ROWS` | 5000 | max participants per batch |
| `CERTIFLOW_WORKERS` | 2 | certificates are generated by this many background threads |
| `CERTIFLOW_RETENTION_HOURS` | 24 | uploads, PDFs and job records are deleted after this long |
| `TESSERACT_CMD` | auto | path to tesseract if not on PATH |

Built in: unguessable job links, no server paths in API output, per-IP rate limits, security headers, automatic deletion, restart recovery of interrupted jobs, uploaded fonts private to one session.
**Not built in:** user accounts/login, virus scanning, quotas per user. Add a login layer or an upload gateway before exposing it to untrusted users at scale. Anyone with a job link can download that job's PDFs.

## Validation Centre (what is checked)
Missing columns, missing values, **duplicate values** (per field: "Must be unique"), **formats** (per field: date / number / email),
unmatched placeholders, blank rows, unused columns. Column names that differ (e.g. `Full Name` for `{{student_name}}`) are
**suggested, never applied without a click**. All checks are chosen by the user per field; no field name is built in.
