  • Use double braces: {% raw %}{{student_name}}{% endraw %}. Capitals and spaces are fine.

Questions

Good to know

Which files can I use?

Designs: PDF, PNG or JPG. Lists: Excel (.xlsx) or CSV. PDF designs are the most reliable, because their text can be read exactly.

How does it find the placeholders?

In a PDF it reads the text. In a PNG or JPG it reads the picture, so use clear, high-contrast text. If a placeholder is not found, we tell you instead of guessing.

What if my column names are different?

Capitals, spaces and hyphens are ignored. If a name is still different (for example Full Name for {% raw %}{{student_name}}{% endraw %}), we suggest the closest column and you confirm it with one click.

Can I use Telugu, Hindi or other languages?

Yes. Upload a font that supports the language (for example Noto Sans Telugu), choose it for the field, and use “Preview one certificate” to check it.

What happens if some rows have mistakes?

Nothing is generated by accident. The data check lists every problem with its row and name. You can fix the file and upload it again, or skip only those people.

How many certificates can I make at once?

Large batches run in the background with a progress bar. The default limit is 5,000 per batch.

Is my data safe?

Your files are used only to make your certificates and are deleted automatically after 24 hours. Your download link is private, so don't share it with people who shouldn't see the certificates.
